# apxm 0.1.0

This release makes APXM usable through a clear Dekk-first workflow:

- `dekk apxm goal` and `dekk apxm workflow` are the native goal/workflow
  control plane.
- MCP exposes `prompt_as_workflow`, `workflow_*`, and `goal_start` as the
  workflow-oriented public surface.
- Release artifacts are built by `dekk apxm release dist` under
  `.apxm/releases/v0.1.0/`.
- The model-zoo path is the vLLM service launch surface.

Artifacts include the Python package, APXM binaries, a source archive, and
`SHA256SUMS`.
