# Vision — APXM abstract machine

APXM provides a small, typed abstract machine for Agent Programs. Authored
source is behavior truth; FrontendGraph is the language-neutral handoff; AIR
and AIS close the executable semantics; exact admission supplies authority and
implementation bindings; the runtime records monotonic evidence.

The repository stays product-neutral. A product may provide a UI, HTTP
transport, deployment, identity, credentials, or external capability, but
those concerns enter through explicit contracts rather than changing APXM
semantics.
