# Domain — meta

Skill authoring, MCP server, the agent surfaces themselves.

## Skills

- **apxm-mcp-server** — work on the APXM MCP server.

Skill-authoring lives in `apxm-project/apxm-libs`
(`.agents/skills/apxm-skill-authoring/`).

## SSOT

- `.agents/project.md` — the body of every agent config.
- `.agents/skills/_shared/` — shared rules loaded by skills.
- `.agents/skills/<name>/SKILL.md` — individual skill files.

Generated outputs (regenerated by
`dekk apxm skills generate --target all`):

- `AGENTS.md` (Codex CLI, Aider, Cursor, etc.)
- `CLAUDE.md` (Claude Code)
- `.agents.json` (machine-readable manifest)
- `.cursorrules` (Cursor)
- `.github/copilot-instructions.md` (GitHub Copilot)
