## Workload and rationale

- Benchmark: `tau2-bench` (vendored at `tools/external/tau2-bench/`,
  pin sha `0ed8c0ef0a1f6b024a0fb733e186922411874879`).
- Domain: `airline` (50-task suite; same domain and same wire shape
  as the just-shipped N=5 cell at
  `.apxm/docs/claims/agentic-accuracy-airline-n5.md`).
- Sub-sample: first **N=20** tasks per arm by tau2's default ordering;
  same seed in both arms so identical task subsets land in each arm.
- One trial per task (`--num-trials 1`). The pair is therefore 20
  paired binary (pass / fail) observations.
- This run is the **direct higher-power follow-up** to the N=5 cell.
  The N=5 cell produced a +0.20 paired-difference point estimate with
  95% bootstrap CI [+0.000, +0.600] — inside the pre-registered ±0.20
  equivalence band but suggestive of an apxm-on advantage. N=20
  approximately quadruples power; the CI is expected to tighten by
  ~2× and either (a) exclude zero on the favorable side (apxm-on
  superiority claim), (b) tighten around zero (cleaner equivalence
  finding), or (c) shift negative (regression — honest-negative claim).

## Hypothesis under test

- Form (re-stated for the higher-N regime): At N=20 airline tasks
  with the same seed in both arms, the paired-difference
  apxm-on `pass_at_1` − flat-http `pass_at_1` is **either inside the
  ±0.20 equivalence band (no degradation, possibly an advantage too
  small to declare) or has a 95% bootstrap CI excluding 0 in the
  favorable direction (apxm-on superiority claim)**. Both outcomes
  are claim-bearing; the third outcome (CI excluding 0 in the
  unfavorable direction) is an honest-negative claim that apxm-on
  degrades task quality on airline.
- Decision rule:
  - If `lower_CI_95(diff) > 0`: ship as a superiority claim
    ("APXM-on raises airline pass_at_1 by [lower, upper] vs flat-http
    at gpt-oss-120b on the live `vllm-gptoss` zoo service").
  - If `upper_CI_95(diff) < 0`: ship as an honest-negative claim
    ("APXM-on degrades airline pass_at_1 by [lower, upper]") and open
    a Plan 08 follow-up tracking the regression.
  - Otherwise: ship as an equivalence finding at higher N (cleaner
    null), citing the tightened CI.
- Power note: at N=20 the CI width on a binomial-difference point
  estimate of 0.20 is roughly ±0.25 (two-tailed normal approximation),
  so the run is **powered to distinguish a +0.20 difference from
  zero only marginally**. The honest precondition is that the
  expected outcome at this N is "tightened CI, decision rule favors
  equivalence-or-superiority", not "clean superiority claim". A
  N=50+ rerun (full airline suite) is the next escalation if the
  CI still spans zero.

## Honest-negative discipline

- If apxm-on pass-at-1 is **lower** than flat-http with CI
  excluding 0 in the unfavorable direction, ship as honest-negative;
  open Plan 08 ticket tracking the regression with per-task failure
  classes.
- If both arms have agent-error or tau2 system-error rate > 0, the
  cell is not claim-bearing and the partial result is preserved for
  audit only.
- Any divergence in the per-task pass/fail pattern from the N=5
  subset (tasks 0..4) is recorded as run-to-run noise on those five
  tasks (different scheduler decisions in a higher-concurrency
  context can plausibly flip individual outcomes — this is noise,
  not invalidation of the N=5 cell).
