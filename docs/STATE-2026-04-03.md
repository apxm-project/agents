## What Is APXM

APXM is a Rust-based agentic AI runtime with a 4-stage MLIR compiler, a graph-aware execution engine, and a multi-backend LLM dispatch system. It compiles declarative agent workflow graphs (`.apxm`) into optimized execution artifacts, then runs them with parallel scheduling, memoization, circuit-breaker routing, and ACP-agent orchestration.

**15 crates**, ~400 tests passing.
