# APXM Paper Drafts

This directory holds paper-facing drafts and publication figures derived from
the current APXM evaluation evidence.

- [apxm-paper-draft.md](apxm-paper-draft.md) — working systems-paper draft.
- [figures/](figures/) — SVG figures generated by
  `tools/scripts/make_apxm_paper_figures.py`.

Generated figure data is written to `.apxm/evaluation/paper/20260521/`; the
SVG files in this directory are publication assets for the draft.
